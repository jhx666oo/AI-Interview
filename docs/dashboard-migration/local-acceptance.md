# 仪表盘 v3 本地验收

## 自动化验证

在仓库根目录执行：

```bash
npm --prefix worker test
npm --prefix frontend test
npm --prefix frontend run build
```

Worker 的 TypeScript 检查目前仍会显示仓库既有的 Hono 环境类型告警；前端构建会同时编译 Worker，作为本次改动的可执行类型/打包门禁。

## 手工矩阵

1. 用测试账号进入 `/dashboard`，确认页面默认使用 v3：全局七级漏斗、事业部六级 mini 漏斗、HRBP 四段转化、P2 储备岗和 AI 诊断均出现。
2. 切换负责人，确认 KPI、漏斗、事业部和 HRBP 同时收窄，不出现全局总数残留。
3. 管理员点击“保存今日快照”，再切换历史日期，确认 `schema_version=dashboard-v3` 快照可读；旧 v2 快照仍可由旧接口读取。
4. 创建实时和快照分享链接，打开无登录分享页，确认只显示聚合岗位字段，不包含简历正文、候选人姓名、电话、邮箱和 AI 原文。
5. 用不同宽度检查：1440px、1280px、1024px、13 寸常见窗口。页面不产生 body 横向滚动；事业部岗位明细和 P2 明细可折叠展开。
6. 若飞书任一数据源失败，页面保留旧 v2 回退并显示错误提示，不用 0 覆盖真实数据。
