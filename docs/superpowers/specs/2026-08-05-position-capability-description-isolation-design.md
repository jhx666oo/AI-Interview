# 岗位能力维度描述隔离设计

## 目标

岗位编辑页保存能力维度时，只更新当前岗位；不同岗位可以使用相同的能力维度名称，但每个岗位拥有独立描述。

## 方案

- 删除“同步描述到所有岗位的相同维度”交互和对应的批量更新逻辑。
- 保留当前岗位的能力维度 JSON 保存流程，能力维度名称仍可从全局名称池复用。
- 不修改已有岗位数据；上线后新的编辑保存不会再覆盖其他岗位。
- 增加一个纯函数测试，验证保存 payload 只包含当前岗位字段，不产生跨岗位更新计划。

## 验收

1. 编辑“软件产品经理（智能硬件方向）”的维度描述并保存，不会修改“项目经理（智能硬件方向）”。
2. 两个岗位可以拥有同名维度，但描述不同。
3. 前端构建和新增回归测试通过。
