# 简历列表当前页全选设计

## 目标

在简历管理的卡片列表顶部增加“全选本页”复选框，减少逐条勾选的操作成本，同时保持现有跨页批量操作能力与安全范围。

## 交互规则

- 复选框位于批量操作栏左侧，文案为“全选本页”。
- 点击后只选中当前分页可见的简历；再次点击只取消当前页的选择。
- 当前页全部已选时为选中状态；选中部分时为半选状态；当前页没有选择时为未选状态。
- 翻页后不自动选择新页面，但此前其他页的选择保留在 `selectedRowKeys` 中。
- 点击“取消全选”不会清空其他页已选择的简历。
- 既有“已选 N 项”、批量入库、批量淘汰、批量删除及其确认弹窗不改变。

## 实现与验证

- 前端只修改 `frontend/src/pages/Resumes/List.tsx`，从当前分页数据派生 `currentPageIds`、全选状态和半选状态。
- 切换时用 Set 合并/移除当前页 ID，避免重复 ID 或误清除跨页选择。
- 增加组件行为回归测试：全选当前页、半选状态、取消当前页仅保留其他页 ID。
- 运行前端构建，确保现有简历页面类型检查与生产包通过。
